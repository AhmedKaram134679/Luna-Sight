# LunaSight — تصدير بيانات JPL Horizons

## ما الذي يفعله السكربت؟
يطلب من JPL Horizons جدول Observer للجرم Earth (399) من موقع على القمر (301) عند:
- خط الطول الشرقي: 200°
- خط العرض: -88.45°
- الارتفاع: 0 كم
- الفترة: 2026-11-01 07:10 إلى 08:10 UTC
- الفاصل: دقيقة واحدة
- الكميات: السمت/الارتفاع الظاهريان، المسافة ومعدلها، والقطر الزاوي المستهدف.

## التشغيل على Windows
1. حمّل `fetch_lunasight_state_vector.py`.
2. افتح Terminal أو PowerShell داخل المجلد الذي يحتوي الملف.
3. شغّل:
   ```powershell
   py .\fetch_lunasight_state_vector.py
   ```
4. يحتاج السكربت إلى اتصال إنترنت. يستخدم مكتبات Python القياسية فقط.
5. يحفظ استجابة Horizons الخام وبيانات الصفوف المستخرجة في المجلد نفسه.

## تحذير علمي
هذا طلب Observer من JPL Horizons، وليس ضمانًا بأن نموذج الإطار/الدوران القمري يطابق إعداد `MOON_ME` في التصدير السابق حرفيًا. يجب مراجعة رأس الاستجابة ومقارنة الإحداثيات والتصحيحات قبل استخدام القيم لحسم توقيت الحدث. لا تُستخدم بيانات غير ناجحة أو ناقصة.
