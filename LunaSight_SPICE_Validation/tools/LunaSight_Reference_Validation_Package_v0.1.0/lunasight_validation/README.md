# LunaSight validation package (diagnostic v0.1.0)

## Contents
- `VALIDATION_REPORT.md`: current findings, blockers, and next reference-data capture.
- `source_manifest.json`: observer metadata, known configuration mismatch, and checksums.
- `raw_sources/`: original source exports preserved unchanged.
- `validate_package.py`: offline diagnostic checks; it does not certify event timing.
- `validation_run.json`: generated by running the checker.

## Run
Requires Python 3.10+ and no third-party packages:

```bash
python validate_package.py
```

The script should finish with a package diagnostic PASS and explicitly retain the scientific event status as UNVERIFIED. This is intentional.
