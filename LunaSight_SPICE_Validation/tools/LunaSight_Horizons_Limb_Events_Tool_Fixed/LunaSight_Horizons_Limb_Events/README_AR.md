# أداة LunaSight — تحديد عبور حافتي قرص الأرض للأفق

## التشغيل على Windows

1. تأكد من تثبيت Python.
2. افتح PowerShell داخل هذا المجلد.
3. ثبّت الاعتماد المطلوب إذا لم يكن موجودًا:
   `py -m pip install truststore`
4. شغّل:
   `py .\fetch_lunasight_limb_events.py`

## ما الذي تم إصلاحه؟

قد يعيد JPL Horizons الطابع الزمني للبيانات ذات الفاصل الزمني بالدقائق بصيغة `2026-Nov-01 07:30` دون الثواني، حتى عند طلب `TIME_DIGITS=SECONDS`. أصبح المحلل يقبل الصيغ الثلاث: `YYYY-Mon-DD HH:MM`, و`YYYY-Mon-DD HH:MM:SS`, و`YYYY-Mon-DD HH:MM:SS.fff`، مع الاستمرار في التحقق من وجود ثمانية أعمدة على الأقل وتحليل الأعمدة الرقمية الصحيحة.

الأداة تحفظ الاستجابة الخام قبل تحليل الصفوف. إذا فشل التحليل لأي سبب آخر، أرسل رسالة الخطأ كاملة وملف الاستجابة الخام الناتج.

## حدود علمية

الحساب يقدّر عبور الحافتين من ارتفاع مركز الأرض ونصف قطرها الزاوي (نصف القطر = القطر الزاوي / 7200). لا يحاكي التضاريس المحلية أو الصخور أو عدم انتظام أفق القمر. أوقات العبور المستنتجة بالاستيفاء تقديرات عددية وليست دقة فيزيائية على مستوى المللي ثانية.
